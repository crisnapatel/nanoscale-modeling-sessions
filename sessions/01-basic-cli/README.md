# Session 1: Linux Command-Line Basics

This session introduces the command-line operations we will use throughout the molecular dynamics series. It assumes no previous Linux experience and uses Ubuntu as the working environment.

The recorded discussion is mostly in English, with some Hindi.

## Materials

- [Command-line notes in Markdown](01-command-line-basics.md)
- [Command-line notes as PDF](01-command-line-basics.pdf)

## Topics covered

- GUI, CLI, terminal, shell, and Bash
- Files, directories, paths, and permissions
- Creating and editing files with Nano
- `pwd`, `ls`, `cd`, `mkdir`, `touch`, and `cat`
- Searching with `grep`, pipes, and Ripgrep (`rg`)
- Copying, moving, renaming, and removing files
- Aliases and `.bashrc`
- Connecting to a remote Linux machine with SSH
- Ubuntu through Windows Subsystem for Linux (WSL)
