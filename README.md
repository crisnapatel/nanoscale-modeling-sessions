# Nanoscale Modeling Sessions

Companion notes, exercises, and simulation files for the practical sessions published on the **Nanoscale Modeling** YouTube channel.

The series starts with the Linux command line and then moves into molecular dynamics with LAMMPS. Each session directory contains the files needed to follow the corresponding video without relying on a prepared software interface.

## Using the material

Open the directory for a session and follow its README. Markdown notes can be read directly on GitHub, and a PDF copy is included when useful for offline reading.

Simulation sessions will include source inputs and small reference outputs. Large trajectories, restart files, and other generated data will not be stored in the repository unless they are needed to reproduce a specific result.
